COMMANDS (EASY VERSION – CALCULATOR CORBA)

---

## STEP 1: Open terminal in project folder

(Right click folder → Open in Terminal)

---

## STEP 2: Compile IDL

idlj -fall CalculatorModule.idl

---

## STEP 3: Compile Java files

javac *.java CalculatorModule/*.java

---

## STEP 4: Start Naming Service

orbd -ORBInitialPort 1050

---

## STEP 5: Run Server (new terminal)

java CalculatorServer -ORBInitialPort 1050

---

## STEP 6: Run Client (another terminal)

java CalculatorClient -ORBInitialPort 1050

---

## FINAL ORDER (REMEMBER)

1. idlj
2. javac
3. orbd
4. server
5. client

---
