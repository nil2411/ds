ASSIGNMENT
TITLE: Multi-threaded Client-Server Communication using Java RMI (Ubuntu Version)

--------------------------------------------------

PROJECT FILES

Client.java
Server.java
ServerImpl.java
ServerIntf.java

(All files must be in SAME directory)

--------------------------------------------------

PART 1: OPEN TERMINAL

Step 1: Open Terminal

Press Ctrl + Alt + T
OR open Terminal from applications

--------------------------------------------------

PART 2: NAVIGATE TO PROJECT FOLDER

Step 2: Move to your project directory

Example:
cd ~/Desktop/ds/Assignment\ 1

OR
cd "~/Desktop/ds/Assignment 1"

--------------------------------------------------

PART 3: COMPILE ALL FILES

Step 3: Compile Java files

Command:
javac *.java

This generates:
Client.class
Server.class
ServerImpl.class
ServerIntf.class

--------------------------------------------------

PART 4: GENERATE STUB (OPTIONAL)

Step 4: Generate Stub class (only for old Java versions)

Command:
rmic ServerImpl

(Note: Modern Java versions do NOT require this step)

--------------------------------------------------

PART 5: START RMI REGISTRY

Step 5: Start RMI Registry (IMPORTANT)

Run in SAME folder:

rmiregistry

OR (recommended):

rmiregistry 1099 &

(Default port = 1099)

Keep this running.

--------------------------------------------------

PART 6: RUN SERVER

Step 6: Open NEW terminal

cd ~/Desktop/ds/Assignment\ 1

Step 7: Run Server

Command:
java Server

Expected Output:
Server started...

Server registers remote object with RMI Registry

--------------------------------------------------

PART 7: RUN CLIENT

Step 8: Open ANOTHER terminal

cd ~/Desktop/ds/Assignment\ 1

Step 9: Run Client

Command:
java Client

--------------------------------------------------

FINAL EXECUTION ORDER

1. javac *.java
2. rmiregistry
3. java Server
4. java Client

--------------------------------------------------

WORKING FLOW

Client → calls remote method
→ RMI Registry finds server
→ ServerImpl executes method
→ Result returned to Client

--------------------------------------------------

MULTI-THREADING CONCEPT

- RMI server handles multiple clients
- Each client request runs in a separate thread
- Multiple clients can connect simultaneously

--------------------------------------------------

COMMON ERRORS

1. Connection refused
   Cause: Registry not started
   Fix: Run rmiregistry

2. Class not found
   Cause: Compilation issue
   Fix: Run javac *.java

3. Port already in use
   Cause: Registry already running
   Fix:
   ps -ef | grep rmiregistry
   kill -9 <PID>

4. Permission issues
   Fix:
   chmod +x *.java

--------------------------------------------------

IMPORTANT NOTES

- All files must be in same directory
- Run rmiregistry BEFORE server
- Run server BEFORE client
- Keep registry running
- Ensure Java is installed

Check Java:

java -version
javac -version

--------------------------------------------------

CONCLUSION

The program demonstrates distributed client-server communication using Java RMI on Ubuntu. The server handles multiple clients concurrently using multi-threading, allowing efficient remote method execution.

--------------------------------------------------
